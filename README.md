## Features
 - 3x3 Mining Hammer (Pickaxe)
 - 3x3 Excavator (Shovel)
 - Tools are enchantable
 - Several material tiers
   - Stone
   - Copper
   - Gold
   - Iron
   - Diamond
   - Netherite
